# Sims Needs Meter

This 3D printable "needs meter" is inspired by the Sims games.

It offers a non-verbal option to communicate someone's current needs through 8 sliders.
 - 🍴 Hunger
 - 🛋️ Comfort
 - 🧻 Bladder
 - 😴 Energy
 - 🥳 Fun
 - 💬 Social
 - 🧼 Hygiene
 - 🚪 Environnment
